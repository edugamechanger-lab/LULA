# LULA

Одностраничная веб-игра для тренировки рода французских существительных (A1).

## Запуск

```bash
python -m http.server 4173 --bind 0.0.0.0
```

Откройте `http://localhost:4173`.

## Режимы

- **LULA Basic** — одно слово, перетаскивание в зоны **LE/LA**, моментальный фидбек с правилом, коллокациями и переводом.
- **LULA Cloud Timer** — облако слов, настраиваемые `N` (3–20) и таймер (15/20/30 сек), подсветка результатов после окончания времени, разбор по клику по каждому слову.

Данные находятся в `words.js` (100 слов, включая случаи с `l’`).
